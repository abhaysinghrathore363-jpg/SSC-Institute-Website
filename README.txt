INSPECTOR SSC ACADEMY WEBSITE — VS CODE SETUP

FILES
- index.html       Home page + enquiry form
- courses.html     Explore Courses page
- ssc-cgl.html     SSC CGL details
- ssc-cpo.html     SSC CPO / SI details
- ssc-chsl.html    SSC CHSL details
- ssc-mts.html     SSC MTS details
- delhi-police.html Delhi Police details
- ssc-gd.html      SSC GD details
- style.css       Shared styling
- script.js       Navigation + WhatsApp form behaviour

HOW TO OPEN
1. Extract this ZIP into one folder.
2. Open that folder in VS Code.
3. Open index.html with Live Server (or double-click index.html).

IMPORTANT DETAILS TO CONFIRM WITH THE ACADEMY
- Actual batch names, batch start dates and class timings
- Course fees, duration, online/offline mode
- Faculty names, classroom photos and academy logo
- Whether all six listed exam batches are currently active

FUNCTIONS
- Talk to Academy opens the phone dialler using tel:+917230072444.
- Start an Enquiry opens WhatsApp with a pre-written batch-information request.
- Send an Enquiry transfers all filled form fields into the WhatsApp message.
- Google Reviews opens the academy's supplied Google Maps listing.
- No server/database is used; the user must press Send in WhatsApp.

CONTENT NOTE
Eligibility, age, post names and selection stages are broad exam guidance. The latest SSC / Delhi Police recruitment notice overrides this website. Please verify details before publication.
